# case-stomatology-Odesa

Статичний односторінковий сайт-візитка для стоматологічної клініки в Одесі.
Чистий HTML / CSS / JavaScript, без фреймворків і збірки — заливається на
звичайний Apache-хостинг як є.

Дві мовні версії як окремі статичні сторінки: `/` (українська) та `/ru/` (російська).
